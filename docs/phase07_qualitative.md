## 0. 이 단계의 성격

Phase 1~6은 숫자를 만드는 단계였습니다. **Phase 7은 숫자로 만들지 못한 것을 기록하는 단계입니다.**

비용표에 없는 항목은 비용이 없는 것처럼 보입니다. 계층화가 유리하다는 결론이 나왔으므로, **그 결론의 전제가 성립하지 않는 조건을 미리 다루지 않으면 발표 자리에서 반론에 무방비가 됩니다.**

선행 프로젝트에서 캐시 미스 지연과 아카이브 회수 지연을 금액으로 만들지 않고 별도 항목으로 서술한 것과 같은 처리입니다.

## 2. 영향 방향 분류 — 본 단계의 핵심

**각 항목이 "계층화가 유리하다"는 결론을 강화하는지 약화하는지를 분류합니다.**

| # | 항목 | 방향 | 무게 |
|---|---|---|---|
| 1 | **니어라인 HDD 조달 제약** | **약화** | **높음** |
| 2 | **아카이브 회수의 수동성** | **약화** | **높음** |
| 3 | 오브젝트 스토리지 국내 저경쟁 | **약화** | 중간 |
| 4 | 2026-10-31 접속기록 대상 확대 | **약화** | 낮음 |
| 5 | 감축 보증의 실효성 제약 | **강화** | 중간 |
| 6 | 성능(IOPS·지연) | 중립 | 낮음 |
| 7 | 판정 안정성 문턱값의 자의성 | 중립 (자기 한계) | — |

**약화 4건, 강화 1건입니다.** 결론을 그대로 두되 **적용 조건을 명시하는 방향으로 서술해야 합니다.**

## 3. 항목별 상세

### 3.1 니어라인 HDD 조달 제약 — 약화, 무게 높음

Phase 2에서 확인한 내용을 재조회했습니다. **한 달 사이 상황이 악화되었습니다.**

| 확인 사항 | 내용 |
|---|---|
| Seagate | 니어라인 생산능력이 2026년 전량 배분 완료. 2027년 상반기 주문을 이제야 접수 시작 |
| Western Digital | 2026년 사실상 완판. 상위 7개 고객 확정 주문. 2027·2028년 장기계약 체결 |
| 리드타임 | 몇 주에서 **52주 이상**으로 확대 |
| 생산능력 확대 | **하지 않음.** 성장은 대용량 드라이브로만 |
| 제조 리드타임 | 12~18개월. 반도체보다 훨씬 느림 |
| 니어라인 비중 | Seagate HDD 매출의 87% (전년 83%) |

**본 프로젝트에 결정적인 지적**

한 조사기관 애널리스트는 HDD 제조 능력이 대형 클라우드 사업자에게 거의 독점적으로 배분되고 있으며, **이것이 중견 규모 시장에 타격을 준다**고 지적했습니다. 다른 조사기관의 연구책임자는 **일반 기업용 서버와 엔터프라이즈 스토리지에 매우 어려운 해가 될 것이며 해당 시장의 전망을 하향 조정했다**고 밝혔습니다.

> **본 프로젝트의 대상은 국내 중견 이커머스입니다. 하향 조정된 그 시장입니다.**

**의미**

계산상 계층화가 유리해도 **대체 계층 매체를 조달하지 못하면 전제가 성립하지 않습니다.** Phase 2에서 지적한 "시장 지수의 분모가 제조사 어느 쪽도 신규 고객에게 제시하지 않는 가격"이라는 문제가 그대로 유효합니다.

**정량화하지 않은 이유:** 조달 가능 물량과 대기 기간을 수치화할 근거가 없습니다. 리드타임 52주는 관측치이나, 그것이 특정 조직의 조달 실패 확률로 환산되지 않습니다. 넣으면 가정만 늘어납니다.

### 3.2 아카이브 회수의 수동성 — 약화, 무게 높음

**이번 단계에서 새로 조사한 항목입니다.**

Phase 3에서 아카이브 계층은 색인이 제거된다고 확인했습니다. 그 결과가 실무에서 무엇을 뜻하는지 확인했습니다.

| 확인 사항 | 내용 |
|---|---|
| 검색 가능 여부 | **동결된 버킷은 검색되지 않습니다** |
| 복구 절차 | ① 시각 범위로 버킷 선택 → ② thawed 디렉터리로 복사 → ③ `splunk rebuild` 실행 |
| 접근 방식 | **명령줄 수동 작업** |
| 제약 | 버킷 식별자가 기존과 충돌하지 않아야 함 |
| 난이도 | 다수 버킷 중 시각으로 올바른 것을 고르는 작업이 쉽지 않다는 서술 |
| 부작용 | 복원된 데이터는 보존 정책 대상에서 제외되어 **수동 삭제가 필요** |

> **계층화의 대가는 "느려진다"가 아닙니다. "관리자가 명령줄로 수동 복구해야 한다"입니다.**

**왜 이것이 결론을 약화하는가**

Phase 5·6은 즉시검색 기간을 90일로 줄이는 것을 안전한 답으로 제시했습니다. **그러나 91일 전 데이터가 필요해지는 순간, 그것은 조회가 아니라 복구 작업입니다.**

침해사고 조사처럼 시간이 촉박한 상황에서 이 절차가 필요해지면 실질 비용이 발생합니다. **금액으로 환산할 근거는 없으나, 계층화 강도를 정할 때 반드시 고려해야 할 요인입니다.**

**정량화하지 않은 이유:** 복구 소요 시간은 버킷 수, 용량, 하드웨어에 따라 달라지며 공개 실측치가 없습니다. 사고 대응에서 이 지연이 얼마의 손실로 이어지는지는 조직마다 다릅니다.

### 3.3 오브젝트 스토리지 국내 저경쟁 — 약화, 무게 중간

Phase 2에서 확인한 국내 조달 경쟁 구조입니다.

| 사업 유형 | 투찰률 | 참여사 |
|---|---|---|
| 매체 단독 구매 3건 | 88~89% | 8~19곳 |
| **오브젝트 스토리지 구축** | **98.2%** | **2곳** |

**계층화 대상 매체를 국내에서 조달할 때 가격 협상 여지가 구조적으로 좁습니다.** 일반 디스크 증설은 경쟁으로 11~12% 할인되지만, 오브젝트 스토리지는 예정가에 거의 붙어서 낙찰됩니다.

**의미:** 본 분석은 아카이브 단가를 소매 니어라인 기준으로 잡았습니다. **실제 국내 조달에서는 그보다 비싸게 살 가능성이 있으며, 그만큼 계층화의 이득이 줄어듭니다.**

### 3.4 2026년 10월 시행 접속기록 대상 확대 — 약화, 무게 낮음

접속기록 보관 대상이 개인정보취급자에서 **개인정보처리시스템에 접속한 자(정보주체 제외)**로 확대됩니다. 시행일은 2026년 10월 31일입니다.

**이것은 예측이 아니라 이미 공포된 법령의 확정된 시행일입니다.** 원칙 14항과 충돌하지 않습니다.

**그러나 로그량 증가폭을 산정할 근거가 없습니다.** 오픈마켓 판매자처럼 비정규 이용자가 얼마나 되는지는 조직마다 다릅니다.

> 본 분석은 이 조항을 반영하지 않았습니다. 다만 **5년 계산 기간 중 4년 이상이 시행 이후에 해당**하므로, 실제 소요 용량은 본 분석보다 클 가능성이 있습니다.

**왜 약화인가:** 로그량이 늘면 총액이 커집니다. 임계 배수는 로그량과 무관하므로 판정은 바뀌지 않으나, **예산 계획의 정확도가 떨어집니다.**

### 3.5 감축 보증의 실효성 제약 — 강화, 무게 중간

Phase 1에서 확보한 약관에서 다음 조건을 확인했습니다.

| 조건 | 내용 |
|---|---|
| 발동 요건 | 물리 SSD 공간의 **50% 이상**에 데이터가 기록되기 전에는 보증이 발동하지 않음 |
| 구제 방식 | 현금 배상이 아니라 튜닝·마이크로코드 재구성·추가 하드웨어 중 **제조사 재량 선택** |
| 추가 용량 상한 | 제품 물리 용량의 50% 이내 |
| 청구 제한 | **제품당 1회**, 보증 기간 만료 전 서면 접수 |
| 약관 명시 | 특정 감축률 달성을 보증하는 것이 아니라 **미달 시 구제 수단을 규정한 것** |

**왜 결론을 강화하는가**

감축 레버가 문서상 수치보다도 실무에서 더 약하다는 뜻입니다. **6:1이라는 숫자가 계약상 달성 약속이 아니며, 미달해도 현금으로 돌려받지 못합니다.**

Phase 1에서 본 워크로드의 감축 상한이 3.33임을 확인했는데, **그 3.33조차 보증 대상이 아닙니다.** 계층화 우위 결론이 그만큼 더 견고해집니다.

### 3.6 성능(IOPS·지연) — 중립, 무게 낮음

Phase 0에서 범위 제외로 확정한 항목입니다. 계층 이동의 대가이나 금액 환산 근거가 없습니다.

**중립으로 분류한 이유:** 본 프로젝트가 정의한 계층 경계는 **즉시 검색이 필요한 기간**입니다. 그 기간 안의 데이터는 플래시에 있으므로 성능 저하가 없고, 밖의 데이터는 애초에 즉시 검색 대상이 아닙니다. **경계를 올바르게 잡았다면 성능 문제는 발생하지 않습니다.**

다만 3.2절에서 본 대로 **경계를 잘못 잡았을 때의 대가는 성능 저하가 아니라 수동 복구**입니다. 실질적인 위험은 그쪽입니다.

### 3.7 판정 안정성 문턱값의 자의성 — 자기 한계

Phase 6에서 **"확률이 한쪽으로 90% 이상 쏠려야 안정"**이라는 기준을 사용했습니다. **이 문턱값은 근거 문헌 없이 설정했습니다.**

| 문턱값 | 60일 기준 판정 (확률 87.2%) |
|---|---|
| 80% | **안정** |
| **90% (채택)** | **불안정** |
| 95% | 불안정 |

**문턱값을 80%로 바꾸면 60일 기준이 안정으로 분류됩니다.** 즉 이 하나의 자의적 선택이 권고 기간을 60일과 90일 사이에서 바꿉니다.

**이 사실을 결과와 함께 제시합니다.** 자기 방법론의 약점을 스스로 적지 않으면 문서 전체의 신뢰도가 떨어집니다.

## 4. 결론이 뒤집히는 조건

**본 분석의 결론이 유효하지 않게 되는 조건입니다.**

| # | 조건 | 근거 |
|---|---|---|
| 1 | **니어라인 HDD 또는 오브젝트 어플라이언스를 조달할 수 없는 경우** | 3.1절. 계층화의 물리적 전제가 성립하지 않음 |
| 2 | **91일 이전 데이터에 대한 즉시 조회 요구가 실제로 발생하는 경우** | 3.2절. 복구가 아니라 조회가 요구되면 계층 경계를 다시 잡아야 함 |
| 3 | **국내 조달 단가가 소매 니어라인 기준을 크게 상회하는 경우** | 3.3절. 저경쟁 구조로 협상 여지가 좁음 |
| 4 | **복제 구성이 단일 인덱서이면서 즉시검색 60일 이하를 요구하는 경우** | Phase 6. 수용 가능 확률 48.6% |
| 5 | **색인 감축률이 실측에서 4:1을 크게 상회하는 경우** | Phase 1·6. 임계 배수가 17.6까지 상승 |

**1번과 2번이 가장 중요한 요인입니다.** 둘 다 금액이 아니라 **가능 여부**의 문제이므로, 계산으로는 답할 수 없습니다.

## 5. 확정 항목

| 판단 | 내용 | 근거 |
|---|---|---|
| 영향 방향 분류 도입 | "영향이 있다"가 아니라 "결론을 약화한다"까지 명시 | 2절 |
| 금액 환산 전면 배제 | 7건 모두 근거 없음 | 3절 |
| HDD 조달 제약을 최우선 배치 | 대상 시장이 직접 지목됨 | 3.1절 |
| 회수 수동성을 신규 조사 | 계층화의 실무 대가가 성능이 아님을 확인 | 3.2절 |
| 뒤집히는 조건을 목록화 | 결론과 나란히 제시 | 4절 |
| 자기 한계 포함 | 문턱값 자의성을 결과에 명시 | 3.7절 |
| **서술 강도 완화 권고** | **약화 4건 대 강화 1건** | 2절, 7절 |

### 서술 강도를 완화하기로 한 이유

세 가지입니다.

1. **약화 항목이 수적으로 우세합니다.** 4건 대 1건이며, 그중 둘은 무게가 높습니다.
2. **약화 항목 두 건이 "가능 여부"의 문제입니다.** 조달 불가와 수동 복구는 비용 문제가 아니라 실행 가능성 문제이므로, 계산 결과보다 상위에 있습니다.
3. **대상 시장이 명시적으로 지목되었습니다.** 조사기관이 중견 기업 시장 전망을 하향 조정했다고 밝힌 이상, "계층화하십시오"를 조건 없이 쓸 수 없습니다.

**다만 결론 자체를 뒤집지는 않습니다.** 계산은 여전히 계층화 우위를 가리키며, 3.5절은 오히려 결론을 강화합니다. **결론을 유지하되 적용 조건을 명시하는 방식**이 근거에 부합합니다.

## 11. 후속 단계

Phase 8은 **서술(벤더 중립 본체)**입니다. Phase 7이 서술의 강도와 구조를 결정했습니다.

| 항목 | 내용 |
|---|---|
| 결론 유지 여부 | **유지.** 계산 결과가 뒤집힌 것이 아님 |
| 서술 강도 | **완화.** 적용 조건을 결론과 같은 위치에 명시 |
| 뒤집히는 조건 | **부록이 아니라 본문에 배치** |
| 자기 한계 | **포함.** 문턱값 자의성과 국내 재고 미확인 |

**Phase 8에서 다룰 서술 순서를 다음과 같이 제안합니다.**

1. 계층화의 이득은 배수가 아니라 색인 제거에서 나온다 (Phase 4)
2. 그 이득은 가용성 요건에 잠식되나 잠식되고도 남는다 (Phase 3·4)
3. 다만 판단의 확실성은 여유가 아니라 불확실성의 폭이 정한다 (Phase 6)
4. **그리고 계산 전체가 두 전제 위에 서 있다 — 조달 가능성과 경계 밖 조회 부재** (Phase 7)

네 번째를 마지막에 두는 이유는, **앞의 세 문장이 계산의 결과이고 네 번째가 계산의 한계이기 때문**입니다. 한계를 먼저 말하면 결과가 묻히고, 제외하면 반론에 무방비가 됩니다.
